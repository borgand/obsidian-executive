# Start here

This vault exists to exercise the Executive theme. Open each note in both Reading view and Live Preview, then switch Obsidian between light and dark under Settings > Appearance and check that nothing keeps the colours of the other mode.

## Notes in this vault

1. [[01 Headings]] - all six heading levels
2. [[02 Inline formatting]] - bold, italic, highlight, code, links and tags
3. [[03 Lists and quotes]] - nested lists, tasks and blockquotes
4. [[04 Callouts]] - every Obsidian callout type and the GitHub alert forms
5. [[05 Tables and footnotes]] - a table and a few footnotes
6. [[06 Properties]] - a note with YAML front matter
7. [[07 Code]] - fenced code in several languages
8. [[08 Math]] - inline and block math
9. [[09 Mermaid]] - flowchart, sequence, state and class diagrams
10. [[10 Image and rule]] - an embedded image and a horizontal rule

The theme is linked into this vault by `scripts/link-vault.sh`. If the theme does not appear under Settings > Appearance, run that script from the repository root first.
